# Certify

## Platform
Web application, Next.js App Router and TypeScript, hosted on Vercel with Supabase authentication and storage.

## Product truth
Users import recipient spreadsheets or Google Sheets, position personalized text on uploaded certificate artwork, generate PDFs locally, preview results and explicitly send certificates. Google login and optional Gmail authorization are separate. Sending is never triggered by login. Existing identity, ownership, consent, token-storage and delivery rules must remain intact.

## Current brief
On 15 October 2026 the user delegated a visual redesign to make the application more attractive and contemporary. No deployment or production-setting changes are included. Audience segmentation beyond certificate creators is unknown; do not invent customer claims, usage metrics or testimonials.
